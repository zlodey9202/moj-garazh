МОЙ ГАРАЖ — установка на iPhone

В приложении данные хранятся локально в браузере/веб-приложении на устройстве.
Для установки на главный экран iPhone нужен HTTPS-адрес.

ПУБЛИКАЦИЯ (один раз):
1. Создайте аккаунт на GitHub (если его ещё нет).
2. Создайте новый публичный репозиторий, например moj-garazh.
3. Распакуйте архив и загрузите в корень репозитория файлы index.html, manifest.webmanifest, sw.js, icon.svg.
4. В репозитории откройте Settings → Pages.
5. В разделе Build and deployment выберите Deploy from a branch, ветку main и папку /(root), нажмите Save.
6. Дождитесь публикации и откройте выданный GitHub Pages URL в Safari на iPhone.
7. Нажмите Поделиться → На экран Домой → Добавить.

ИСПОЛЬЗОВАНИЕ:
- Открывайте приложение с добавленной иконки на главном экране.
- Вносите пробег, обслуживание, расходы, топливо, детали, замеры аккумулятора, фото и заметки.
- Регулярно делайте резервную копию: Настройки → Экспорт данных.
- Для восстановления используйте Импорт данных.

ВАЖНО:
Данные хранятся на конкретном устройстве и в хранилище установленного веб-приложения. Не очищайте данные сайта/приложения без резервной копии. При открытии на другом устройстве данные автоматически не синхронизируются.
